Privacy policy

Privacy

This page describes what data OpenCode Google Tools can access and what happens to it. Last updated: 14 November 2026.

Scope

OpenCode Google Tools is a personal OpenCode integration intended only for its owner's Google accounts. It is not a hosted service and does not operate a backend.

Data accessed with your consent

After you grant OAuth consent, the tool may access data in Google products when you request it, including:

  • Google Docs documents and their content, structure, comments and tabs.
  • Google Sheets spreadsheets, sheets, ranges and values.
  • Google Drive files and folders.
  • Gmail messages, labels, filters, drafts and sending when you ask the agent to use Gmail.
  • Google Calendar calendars, events, free/busy information and event creation when you ask the agent to use Calendar.
  • Google Apps Script projects, script content and deployments when you ask the agent to manage Apps Script.

Google API Services User Data Policy

OpenCode Google Tools' use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

The integration does not use Google user data to train generalized models, sell user data, or share user data for unrelated purposes.

Storage and security

Access happens from your computer using an OAuth token. The token is stored locally in the OpenCode Google Tools directory on your machine. The token is not transmitted to the publisher of this integration as a central service, and this project does not provide a remote token store.

You can revoke access at any time through Google Account Permissions. Revocation stops future access immediately. You are responsible for protecting your machine, token file, and credentials.

Sharing

Your Google data is sent only to Google's APIs to perform the action you requested. It is not shared with unrelated third parties, analytics providers, or advertising networks.
